## 📖 Description

LeafUp은 꾸준히 하기 어려운 환경보호를 게임 형식으로 즐길 수 있게 도와주는 서비스입니다.

실시간 카메라 인증을 통해 환경 보호 챌린지를 수행할 수 있고, 스테이지 형식으로 챌린지들이 주어집니다.

챌린지를 완수하면 포인트가 주어지고, 이 포인트로 귀여운 캐릭터를 꾸밀 수 있습니다.

동네 순위, 전체 순위, 친구 순위를 제공해 경쟁심을 자극하여 즐겁게 즐길 수 있습니다.
